# ChronoX

**A luxury watch store** — timeless classic pieces, a hero carousel, shop, product pages, cart and login.

**Live:** [chronox20.vercel.app](https://chronox20.vercel.app)

## Pages
- `index.html` — entry, opens the store
- `Chrono.html` — home with the hero carousel
- `shop.html` — the collection
- `product.html` — a single watch

## Built with
HTML · CSS · JavaScript · Bootstrap 5

## Run it locally
No build step — open `index.html` in a browser.
